# Data Setup

This project expects the raw source dataset at:

`data/raw/master_data.csv`

## Steps
1. Obtain the original tourism dataset (`master_data.csv`) from your assignment source.
2. Place it in `data/raw/`.
3. Run the pipeline from repo root:
   - `python3 run_pipeline.py`

## Notes
- Raw files are excluded from git using `.gitignore`.
- Keep this folder structure so teammates/reviewers can run the project without editing paths.
